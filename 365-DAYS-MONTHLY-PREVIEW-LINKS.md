# 365 Days of Transformation — Monthly Preview Links

Each `Preview embed URL` is the direct URL used to embed the session in a website. Each `Watch URL` opens the session on YouTube.

## Embed implementation for the developer

Use the **Preview embed URL** as the `src` of an iframe—not as a normal text link. Replace `VIDEO_ID` with the ID listed for that session:

```html
<iframe
  src="https://www.youtube.com/embed/VIDEO_ID?rel=0"
  title="Video title"
  loading="lazy"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
  allowfullscreen>
</iframe>
```

For a normal clickable preview, use the **Watch URL** instead. All 32 current video IDs were validated against YouTube.
